# Menke-Cameroun-
MENKE — Description Officielle du Projet  Présentation  MENKE est une plateforme numérique de mobilité, de voyage et de services connectés conçue pour améliorer la sécurité, la traçabilité et l’organisation des déplacements en Afrique.  Son ambition est de devenir une Super App africaine regroupant plusieurs services du quotidien
