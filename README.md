# MENKE — Prototype MVP v1

> Plateforme africaine de mobilité intelligente et sécurisée  
> *"Votre famille sait où vous êtes."*

## 🚀 Déploiement sur Vercel (5 minutes)

### Étape 1 — Créer un compte GitHub
1. Allez sur [github.com](https://github.com) → **Sign up** (gratuit)
2. Créez un nouveau repository : bouton **+** → **New repository**
3. Nommez-le `menke-app` → **Create repository**

### Étape 2 — Uploader les fichiers
Dans votre repository GitHub, cliquez **uploading an existing file** et déposez **tout le contenu** de ce dossier.

### Étape 3 — Déployer sur Vercel
1. Allez sur [vercel.com](https://vercel.com) → **Sign up with GitHub**
2. Cliquez **Add New Project**
3. Sélectionnez votre repository `menke-app`
4. Cliquez **Deploy** → ✅ C'est en ligne !

Vous obtenez un lien du type :  
**`https://menke-app.vercel.app`**

Partagez ce lien à tous vos collaborateurs. 🎉

## 📱 Fonctionnalités du prototype

### 3 profils navigables
- 👤 **Utilisateur** — Recherche, réservation, paiement, QR code, suivi GPS, SOS
- 🚗 **Chauffeur** — Documents, publication trajet, réservations, scan QR, revenus
- ⚙️ **Admin** — Dashboard, validation chauffeurs, trajets, incidents
